# spigot: Plumber Endpoints Inside a Shiny App

Mounts a 'plumber' router inside a 'shiny' app so hand-written
HTML/JavaScript pages can call R endpoints on the same origin and port,
while 'shiny' provides hosting, per-tab sessions and server push.
