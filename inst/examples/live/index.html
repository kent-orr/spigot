How each number gets here

HTTP
The buttons call spigot.post("increment", {by}). The reply holds the new count. On load, spigot.get("state") reads the count and the number of tabs.
Push
The endpoint calls spigot_broadcast("count", ...), so every open tab hears about every click through spigot.on("count", ...). The server function broadcasts "tabs" when a tab opens or closes.
Bridge
The endpoint also calls spigot_trigger(session, "clicked", by). That sets input$clicked in the calling tab's Shiny session, an observer adds it up, and renderText() updates This tab's clicks, a Shiny output in this hand-written page.
