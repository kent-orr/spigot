spigot minimal example

This page is plain HTML and JavaScript. Every button calls a plumber endpoint that runs inside this Shiny app, on the same origin and port, under /api. The calls are ordinary fetch() requests to relative URLs that carry this tab's Shiny session token, so only open pages of this app can call the API; see www/app.js and api.R.
